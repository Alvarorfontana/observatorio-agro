# Observatorio Agro · módulo GIS de investigación

Leer INTEGRACION-GITHUB-VERCEL.md para probar y publicar. El módulo está preparado en una copia local de observatorio-agro; no fue enviado a GitHub ni desplegado en Vercel.

El frontend principal es src/main.tsx (React/TypeScript), con estilos en src/styles.css. Backend Flask en api/index.py, adaptadores en research_connectors.py, rutas /api/fuentes en research_routes.py.

No se incluyen secretos ni se generan mediciones ficticias. Consultar public/CONEXIONES-INVESTIGACION.md para los 20 servicios seleccionados y estados reales.
