Cargar observaciones verificadas

Importá un CSV UTF-8 con columnas pais,localidad,lat,lon,fecha,observada_c,record_c,fuente. Cada fila debe referirse a la misma estación, variable y definición de máximo histórico. Se rechazan coordenadas, fechas y temperaturas inválidas.

Los datos se procesan localmente en tu navegador; no se almacenan en el servidor.

Metodología y límites

Se calcula ΔT = temperatura máxima observada − máximo histórico comparable. ΔT ≥ 0 indica récord igualado o superado; −1 < ΔT < 0 indica proximidad inferior a 1 °C. Este monitor no infiere récords a partir de imágenes ni combina automáticamente estaciones y reanálisis. Los mapas de municipios completos requieren límites geográficos y datos de cada municipio.

Fuentes oficiales para futuras integraciones: IDEAM Colombia, SMN Argentina, INMET Brasil y OMM. No se afirma conexión automática con estas fuentes.
